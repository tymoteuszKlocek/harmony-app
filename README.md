# Harmony-app

A minimalist app for daily reflection on life quality.
No gamification. No points. Just you.

## Tech Stack
- Frontend: Next.js 14, TypeScript, Tailwind, shadcn/ui
- Backend: Node.js, Express, PostgreSQL, Prisma
- Auth: JWT
- Deploy: Vercel + Railway

## Features
- Daily check-in (4 life areas)
- Entry history
- "Forest" mode (different colors + questions)
- PWA (offline-first)
